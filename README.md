# Excel Data Analytics Portfolio

![Dashboard Preview](Images/1_Salary_Dashboard_Final_Dashboard.gif)

Two Excel projects built while completing Luke Barousse's free 
"Excel for Data Analytics" course, applying PivotTables, Power Query, 
Power Pivot, DAX, and interactive dashboards to a real-world dataset of 
2023 data science job postings.

## 📊 Projects

### [Project 1 — Salary Dashboard](./Project_1-Dashboard)
Interactive salary dashboard with bar chart, map chart, and 
dropdown-based filtering.

### [Project 2 — Data Analysis](./Project_2-Analysis)
Deeper analysis of skills vs. pay, regional salary differences, and 
top in-demand skills using Power Query, Power Pivot, and DAX.
